# Overview

## 笔记简介

- PostgreSQL 源码学习笔记，目录镜像 `src/backend/`，主要介绍 PG 数据库的核心模块运行机制
- 核心模块包括：解析、优化、执行、存储、内存、复制等，详细见相应目录
- 本文档大部分内容以用例和源码调用栈为主，配套讲解视频：[大象db: PG 源码解析](https://space.bilibili.com/306901642)
- assets 目录下包含原始绘图文件，建议使用 Obsidian 打开（需安装 Excalidraw 插件）
